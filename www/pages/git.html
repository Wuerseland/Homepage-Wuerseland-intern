Git Grundlagen

Idee: Es soll ein Repositorium auf dem Server geben. Die Arbeitsversionen sollen von dort aus ausgecheckt werden.

Repositorium anlegen und auf dem Server bearbeiten.

 
Ein Verzeichnis auf dem Server anlegen und ggfs. die Projektdateien dorthin kopieren.
git init
Git-Repositorium anlegen.
 
Erste Datei(en) im Verzeichnis anlegen.
git add
Dateien unter beobachtung stellen. (Stage, Stagen)
git status
Status der vorhadenen Dateien anzeigen. Hier gibt es dann auch Informationen zu evtl. noch nicht hinzugefügten Dateien.
git commit -m "Commit-Nachricht"
Datei-Versionen im Repositorium hinterlegen.
 
 
 
 
 
 

Lokale Version (Branch) anlegen.

 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
git push origin master
